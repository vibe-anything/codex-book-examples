# 앱별 완료 기준: korea-market-dashboard

대상은 루트 `package.json`의 `korea-market-dashboard` Next.js 앱이다. 실행 때 저장소 정체성과 대상 커밋의 `README.md`, `DATA_REPORT.md`, `.env.sample`을 다시 확인한다. 다른 저장소에는 적용하지 않는다. 과거 보고서의 날짜·가격·종목 수는 현재 배포의 기대값으로 고정하지 않는다.

## 배포 화면과 실제 조회

- 프로덕션 `/` 화면의 관심 종목, 주요 종목 순위, 지수 카드·시장 열기, 업종 히트맵을 확인한다. 관심 종목이 비어 있어도 주요 종목 순위 등에서 실제 종목 시세를 확인할 수 있어야 한다. 검증을 위해 관심 종목이나 localStorage를 변경하지 않는다.
- 종목 시세는 Supabase `public.daily_prices` 최신 `trade_date`의 전체 종목을 페이지로 나누어 읽는다. 종가·등락률·거래대금은 각각 `close_price`, `change_percent`, `trading_value`를 사용한다. 출처·기준일·종가 표시가 있어야 한다.
- 지수·시장 열기·업종은 공공데이터 API를 사용한다. 종목과 시장 요약 기준일이 다르면 각각 표시해야 한다. 일별 종가이며 실시간 시세가 아님을 알리고 지수 그래프가 최근 일별 종가임을 표시해야 한다.
- Supabase 실패 시 실제 공공데이터 종목 시세로 전환하는 것은 허용한다. 사용한 출처를 보고한다. 두 경로 실패로 전체가 예시이거나 시장 요약 일부가 예시이면 해당 실제 데이터 완료 기준 위반이다. 예시 배지나 실패 안내를 숨겨 정상으로 보이게 해서는 안 된다.
- 숫자가 표시된 것만으로 실제 조회 성공을 추정하지 않는다. Vercel MCP 화면·응답·관련 요청 증거로 출처·기준일과 실제 데이터임을 교차 확인한다. 서버 렌더링 등으로 실제 조회를 입증할 수 없으면 WARNING이다. 확인을 위해 엔드포인트를 새로 만들거나 외부 시세 API에 자격증명을 넣어 직접 요청하지 않는다. 이 앱은 `app/page.js`에서 서버 조회하며 별도 공개 API 경로가 있다고 가정하지 않는다.
- 공공데이터는 실시간이 아니며 문서상 기준일 다음 영업일 오후 1시 이후 갱신된다. 주말·휴장일을 고려한다. 오늘 날짜와 다르다는 이유만으로 실패 처리하지 않는다. 최신성에 의문이 있지만 확인할 수 없으면 WARNING이다.
- 업종은 같은 기준일의 유효한 KRX 업종 지수만 표시한다. 조선·게임·2차전지·화장품을 유사·테마 지수로 대체하지 않는다. 상세 매핑은 루트 `DATA_REPORT.md`가 기준이다. 유효한 업종의 누락 여부에 따라 칸 수가 달라질 수 있다.

## 환경변수 이름 계약

계약 원본은 `.env.sample`과 `README.md`다. 현재 이름은 아래와 같으며 실행 때 대상 커밋 원본과 다시 대조한다. 계약 파일도 값은 읽거나 출력하지 않고 이름만 추출한다.

| 이름 | 용도 |
|---|---|
| DATA_GO_KR_SERVICE_KEY | 서버의 공공데이터 API 인증. 클라이언트 데이터나 NEXT_PUBLIC_ 변수로 노출 금지 |
| NEXT_PUBLIC_SUPABASE_URL | Supabase 공개 조회 주소 |
| NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY | Supabase 공개 읽기 키 |

현재 접근 지점은 `lib/dataGoKr.js`, `lib/supabaseMarketData.js`다. 이 목록만 검사하지 말고 실행 코드와 설정 전체에서 추가 요구 이름을 찾는다. 공개용 이름이어도 실제 값을 조회하지 않는다. 계약에 없는 앱 전용 변수 요구는 BLOCKED다. 이 참조 문서만 고쳐 계약 불일치를 덮지 않는다.

## MCP 부족 시 사람이 확인할 내용

- 배포 상태: Vercel의 해당 프로젝트에서 최신 Production 배포의 Ready와 저장소 최신 커밋 SHA를 비교한다.
- 배포 화면·API: 같은 프로덕션 주소를 직접 열어 출처·기준일·종가, 주요 영역의 실제 시세 및 예시 여부를 확인한다.
- 런타임 로그: 같은 배포의 최근 60분 Runtime Logs와 화면 조회 시각을 포함해 반복 5xx를 확인한다.
- 환경변수 계약: 값을 열지 않고 코드의 요구 이름과 `.env.sample`·`README.md`의 이름을 비교한다.
- Git 비밀 검사: 완전한 이력을 가진 승인된 환경에서 현재 추적 파일과 모든 이력의 환경 파일·비밀을 원문 노출 없이 검사한다.

이 안내는 자동 검증의 미확인을 대체하지 않는다. 해당 행은 WARNING으로 유지한다.
