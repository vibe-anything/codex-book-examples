# 16장 프롬프트 모음

아래 요청문은 `vibecoding-codex-book-examples/ch16` 폴더에서 `codex`를 실행한 뒤, 장의 흐름에 맞춰 하나씩 복사해 붙여넣습니다.

공공데이터포털 인증키 값은 Codex 대화나 코드에 붙여넣지 않습니다. `.env` 파일에 직접 입력하고, `.env`가 Git에 올라가지 않는지 확인합니다.

## 0. 작업 폴더에서 Codex 열기

```bash
cd vibecoding-codex-book-examples/ch16
codex
```

## 1. 대시보드에 필요한 공개 데이터 조사하기

```text
지금 구현된 주식 대시보드를 실제 데이터로 채우려면 어떤 공개 데이터가 필요한지 조사해줘.

조건:
- 구현하지 말고 조사만 한다.
- 현재 화면 영역을 기준으로 필요한 데이터와 후보 API를 표로 정리한다.
- 공공데이터포털에서 활용신청할 API 이름과 공식 URL을 남긴다.
- API로 바로 채울 수 있는 칸, 받아 온 값으로 계산해야 하는 칸,
  공개 데이터로 채우기 어려운 칸을 나눠라.
```

## 2. 인증키를 `.env`로 다루게 설정하기

```text
공공데이터포털 인증키를 이 프로젝트에서 .env로 다루게 설정해줘.
- .env 파일을 만들고, 키를 담을 이름을 하나 정한다(예: DATA_GO_KR_SERVICE_KEY).
- .gitignore에 .env가 들어 있는지 확인하고, 없으면 추가해 커밋되지 않게 한다.
- 코드는 인증키를 .env에서 읽어 쓰고, 키 값을 코드에 직접 적지 않는다.
- 실제 키 값은 내가 .env에 직접 넣을 테니, 빈 자리만 만들어 줘.
```

## 3. API 하나가 호출되는지 먼저 확인하기

```text
.env의 DATA_GO_KR_SERVICE_KEY를 써서 공공데이터포털 주식시세정보 API를 한 번 호출해줘.
종목명은 삼성전자, 응답은 JSON으로 받아줘.
응답에서 종가, 등락률, 거래대금, 시장구분 필드 이름과 값의 단위를 표로 정리해줘.
코드는 아직 고치지 말고, 호출 결과만 보여줘.
```

## 4. `/goal`로 수집 연결을 끝까지 진행하기

```text
/goal 목표: 지금 주식 대시보드를 공공데이터포털에서 가져올 수 있는 실제 데이터 기준으로 완성한다.

바꾸지 말 것:
- 지수 카드, 시장 열기, 업종 히트맵, 종목 순위라는 큰 화면 구조
- 외부 데이터가 실패했을 때 예시 데이터로 돌아가는 안전장치

완료 조건(이걸 다 만족해야 끝):
- 현재 화면의 각 영역이 어떤 데이터를 요구하는지 정리한다.
- 공공데이터포털 공식 API로 채울 수 있는 칸과 채울 수 없는 칸을 나눈다.
- 채울 수 있는 칸은 실제 API 데이터나 그 데이터에서 계산한 값으로 연결한다.
- 채울 수 없는 칸은 예시 데이터로 가리지 말고 화면에서 빼거나 나중 기능으로 분리한다.
- 외부 API 실패, 빈 응답, 갱신 지연이 있어도 화면이 깨지지 않게 한다.
- 마지막에 어떤 칸을 유지했고, 어떤 칸을 뺐고, 어떤 API를 썼는지 표로 보고한다.

검증:
- 프로젝트에 이미 테스트나 빌드 명령이 있으면 실행한다.
- 아직 테스트가 없다면 대시보드를 띄워 지수 카드, 시장 열기, 업종 히트맵,
  종목 순위가 깨지지 않는지 확인한다.
- 수집 실패·빈 응답·갱신 지연일 때 화면이 예시 데이터로 버티는지 확인한다.

각 API는 확인을 위해 필요한 만큼만 호출하고, 같은 호출을 반복해서 두드리지 마라.
중간에 막히면 멈추고, 무엇이 됐고 무엇이 남았는지 알려줘.
```
