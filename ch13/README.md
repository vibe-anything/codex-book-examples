# 공공데이터로 동작하는 국내 주식 대시보드

금융위원회의 공공데이터포털 주식시세정보와 지수시세정보를 읽어 최근 공개된
거래일의 시장을 보여 준다. 공공데이터는 실시간 시세가 아니며, 기준 거래일 다음
영업일 오후 1시 이후 갱신될 수 있다.

```bash
npm install
npm run dev
```

공공데이터포털 인증키는 프로젝트 루트의 `.env`에 입력한다.

```dotenv
DATA_GO_KR_SERVICE_KEY=
```

키는 서버 코드에서 `getDataGoKrServiceKey()`로 읽으며, 소스 코드에 직접 적거나
`NEXT_PUBLIC_` 접두사를 붙이지 않는다.

## 화면별 데이터

| 화면 | 데이터 | 처리 방식 |
| --- | --- | --- |
| KOSPI·KOSDAQ 카드 | 종가, 전일 대비, 등락률, 최근 거래일 종가 흐름 | 지수시세정보의 코스피·코스닥 응답 |
| 시장 열기 | 3% 이상 상승 종목 비율 | KOSPI·KOSDAQ 종목의 등락률로 계산 |
| 업종 히트맵 | 8개 업종 등락률 | 지수시세정보의 정확한 KRX 업종 지수 |
| 종목 순위 | 상승률·하락률·거래대금 상위 5개 | 최신 주식시세를 정렬해 계산 |

업종 목록 12개는 유지한다. `반도체·자동차·은행·증권·건설·철강·운송·방송통신`은
각각 같은 이름의 KRX 업종 지수를 사용한다. `조선·게임·2차전지`는 공개 응답에
`TOP 10` 테마 지수만 있어 사용하지 않으며, `화장품`은 대응 업종 지수가 없어
코드의 업종 목록에는 남겨 두되 네 타일은 렌더링하지 않는다.

공공 API 호출 실패, 빈 응답, 두 API의 기준일 불일치, 7일을 넘긴 오래된 응답에는
`data/marketSnapshot.js`의 예시 데이터로 돌아간다.

지수 카드의 미니 차트는 같은 지수시세정보 응답에서 모은 최근 거래일 종가를 잇는다.
공개 API에 장중 시계열이 없어 장중 흐름은 그리지 않으며, 응답에 거래일이 하나뿐이면
그 미니 차트만 비우고 나머지 화면은 실데이터로 그린다.
