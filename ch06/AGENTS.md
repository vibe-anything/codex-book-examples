# 작업 지침

이 프로젝트에서는 사용자와의 응답, 주석, 문서성 설명을 기본적으로 한국어로 작성한다.

- 답은 결론부터 짧게 쓰고, 필요할 때만 자세히 설명한다.

## 프로젝트 개요

- Next.js 기반 실거래가 조회 예제 앱이다.
- 서버 라우트는 `app/api/transactions/route.js`를 사용한다.
- 거래 조회와 파라미터 검증 로직은 `lib/transactions.js`에 둔다.
- 화면 구현은 `app/page.jsx`를 중심으로 유지한다.

## 구현 규칙

- 거래금액은 내부 데이터에서 만원 단위 숫자로 파싱한다.
- 화면에는 거래금액을 억/만 원 단위로 사람이 읽기 좋게 표시한다.
- API 키는 코드에 직접 쓰지 않는다. 서버 환경변수로 `.env`에서 읽고, 클라이언트로 노출하지 않는다.
- 공공데이터 API 키 이름은 기존 코드와 맞춰 `PUBLIC_DATA_SERVICE_KEY`를 사용한다.
- 빈 응답, 인증 오류, 파라미터 오류는 서로 다른 상태로 구분한다.
  - 빈 응답: 조회는 성공했지만 결과가 없는 상태
  - 인증 오류: API 키 누락, 잘못된 키, 권한 문제
  - 파라미터 오류: 지역 코드, 계약년월, 페이지, 행 수 등 입력값 검증 실패
- 서버 응답의 상태값은 화면 메시지와 테스트에서 명확히 판별할 수 있게 유지한다.

## 검증

- 변경 후 기본 검증은 `npm test`로 수행한다.
- Next.js 빌드에 영향을 주는 변경이면 `npm run build`도 확인한다.
- API 키가 필요한 실 API 호출은 `.env` 설정을 전제로 하며, 키 값을 커밋하거나 로그에 남기지 않는다.
