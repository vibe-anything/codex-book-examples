# 앱별 완료 기준: 한국 시장 대시보드

이 파일은 `korea-market-dashboard` 앱에만 적용한다. 일반 절차와 판정 합산은 상위 `SKILL.md`를 따른다.

## 앱 식별

- 저장소 루트: 이 Skill 디렉터리 기준 `../../..`
- 패키지 이름: `korea-market-dashboard`
- 프레임워크: Next.js
- 검증할 프로덕션 경로: `/`
- Vercel 프로젝트 이름을 코드만 보고 추정하지 않는다. Vercel MCP의 Git 연결 정보, 저장소 메타데이터, 프로덕션 도메인을 함께 대조한다.
- 연결 근거가 없거나 둘 이상의 프로젝트가 맞으면 하나를 임의 선택하지 않는다.

## 배포 화면·실제 시세 완료 기준

아래 항목을 프로덕션 주소의 실제 렌더링 결과 또는 Vercel MCP가 제공하는 동등한 배포 응답에서 모두 확인한다.

1. 페이지 제목 또는 헤더에 `시장 한눈에 보기`가 표시된다.
2. 출처 배지가 `Supabase` 또는 `공공데이터`다. `예시 데이터`는 실제 시세가 아니므로 실패다.
3. 출처 옆 기준일이 다음 중 하나로 표시된다.
   - 단일 기준일: `YYYY.MM.DD 기준`
   - 지수·종목 기준일이 다름: `지수 YYYY.MM.DD · 종목 YYYY.MM.DD 기준`
4. `주요 종목 순위` 아래에서 식별 가능한 종목 한 개 이상에 종목명, 0보다 큰 `종가`, 숫자형 `등락률`이 함께 표시된다.
5. `상승률 상위`, `하락률 상위`, `거래대금 상위` 제목이 표시되고, 화면이 오류 안내나 빈 표로 대체되지 않는다.
6. 표시 문구가 실시간 시세라고 주장하지 않고 일별 종가임을 밝힌다.

HTTP 200만 확인했거나 배지·기준일·종가·등락률 중 하나라도 읽지 못했으면 `PASS`로 판정하지 않는다. 실제 값을 다른 금융 사이트와 대조하기 위해 외부 웹 도구를 사용하지 않는다.

## 데이터 소스별 허용 형태

| 출처 | 허용되는 화면 | 필수 확인 |
| --- | --- | --- |
| `Supabase` | 최신 기준일 종목 시세, 지수 카드·업종 히트맵이 없을 수 있음 | 기준일, 종목 순위, 종가, 등락률 |
| `공공데이터` | 금융위원회 일별 지수·종목 시세 | 기준일, KOSPI·KOSDAQ 지수, 종목 순위, 종가, 등락률 |
| `예시 데이터` | 수집 실패용 샘플 | 항상 `BLOCKED` |

## 환경변수 이름 계약

계약의 기준은 빈 값만 둔 저장소 루트 `.env.sample`, 이 표, 그리고 배포 앱 코드의 참조 이름이다. 값의 존재 여부나 내용은 이 검증의 대상이 아니다.

| 환경변수 이름 | 앱 코드 근거 | 저장소 문서 근거 |
| --- | --- | --- |
| `DATA_GO_KR_SERVICE_KEY` | `lib/dataGoKr.js` | `.env.sample`, `README.md`, `API_CHECK.md` |
| `NEXT_PUBLIC_SUPABASE_URL` | `lib/supabaseMarketData.js` | `.env.sample`, `README.md`, `PROMPTS.md` |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | `lib/supabaseMarketData.js` | `.env.sample`, `README.md`, `PROMPTS.md` |

앱 코드 검사 범위에는 `app/`, `components/`, `data/`, `lib/`, `package.json`의 앱 실행 스크립트, 존재하는 `next.config.*`와 `vercel.json`을 포함한다. `test/`, `.codex/`, `.agents/`의 검증 도구가 사용하는 프로세스 환경은 배포 앱 계약에서 제외한다. 단, 앱 코드가 제외 경로의 모듈을 런타임에 import하면 그 모듈도 포함한다.

세 이름의 집합이 어느 한 기준에서라도 달라지면 계약 불일치다. 특히 앱 코드가 표에 없는 이름을 요구하면 배포 화면이 정상이어도 `환경변수 계약`을 `BLOCKED`로 판정한다.

## 런타임 로그 묶음 기준

- 상태 코드 500~599만 5xx로 센다.
- 경로의 쿼리 문자열은 제거한 뒤 같은 경로로 묶는다.
- 오류 메시지는 숫자 ID, 요청 ID, 타임스탬프를 제거한 나머지 문구가 같으면 같은 오류 지문으로 본다.
- 같은 경로 또는 같은 오류 지문에서 2회 이상 발생하면 반복 5xx다.
- 로그에 자격 증명이나 요청 본문이 보여도 보고서에 옮기지 않는다.
