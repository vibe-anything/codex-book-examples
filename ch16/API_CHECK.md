## 현재 화면이 요구하는 데이터

| 화면 영역 | 화면 칸 | 필요한 원천 데이터 | 제공 여부 | 구현 결정 |
| --- | --- | --- | --- | --- |
| 헤더 | 데이터 기준일 | 지수·종목 각각의 `basDt` | 가능 | 두 API의 최신 기준일이 다르면 둘 다 표시한다. 시각은 제공되지 않아 표시하지 않는다. |
| 지수 카드 | KOSPI/KOSDAQ 지수값 | `idxCsf`, `idxNm`, `clpr` | 가능 | 지수시세정보의 `코스피`, `코스닥` 종가를 표시한다. |
| 지수 카드 | 전일 대비, 등락률 | `vs`, `fltRt` | 가능 | 지수시세정보 값을 표시한다. |
| 지수 카드 | 장중 스파크라인 | 시간대별 장중 지수 | 불가 | 지수시세정보는 일별 시가·고가·저가·종가만 제공하므로 스파크라인만 화면에서 뺐다. |
| 시장 열기 | 3% 이상 상승 종목 비율 | KOSPI/KOSDAQ 종목별 `fltRt` | 계산 가능 | `fltRt >= 3`인 종목 수를 유효 종목 수로 나눈다. 별도 공식 “시장 열기” 지표처럼 표시하지 않는다. |
| 업종 히트맵 | 12개 업종명과 등락률 | 정확히 대응하는 업종 지수의 `idxCsf`, `idxNm`, `fltRt` | 일부 가능 | 12개 목록은 코드에 모두 보존하고, 정확한 KRX 업종 지수가 있는 8개 칸만 렌더링한다. |
| 종목 순위 | 상승률·하락률 상위 | 종목명, 시장구분, 종가, 등락률 | 가능 | 주식시세정보의 KOSPI/KOSDAQ 종목을 `fltRt`로 정렬한다. |
| 종목 순위 | 거래대금 상위 | 종목명, 시장구분, 종가, 등락률, 거래대금 | 가능 | `trPrc`로 정렬하고 원 단위 값을 억원·조원으로 표시한다. |
| 종목 순위 | 실시간 현재가 | 장중 실시간 가격 | 불가 | 열 이름을 실제 제공 필드에 맞는 `종가`로 바꾸고 `clpr`만 표시한다. |

## 업종 히트맵 12개 목록 판정

히트맵은 지수시세정보의 정확한 업종 지수만 사용한다. 테마 지수, TOP 지수,
규모 지수는 사용하지 않으며 종목 시세를 합산해 업종 등락률을 만들지도 않는다.

| 화면 업종 | 공식 지수 매핑 | 상태 | 결정 근거 |
| --- | --- | --- | --- |
| 반도체 | `KRX시리즈` / `KRX 반도체` | 유지 | 정확한 KRX 업종 지수 |
| 자동차 | `KRX시리즈` / `KRX 자동차` | 유지 | 정확한 KRX 업종 지수 |
| 은행 | `KRX시리즈` / `KRX 은행` | 유지 | 정확한 KRX 업종 지수 |
| 증권 | `KRX시리즈` / `KRX 증권` | 유지 | 정확한 KRX 업종 지수 |
| 건설 | `KRX시리즈` / `KRX 건설` | 유지 | 정확한 KRX 업종 지수 |
| 철강 | `KRX시리즈` / `KRX 철강` | 유지 | 정확한 KRX 업종 지수 |
| 운송 | `KRX시리즈` / `KRX 운송` | 유지 | 정확한 KRX 업종 지수 |
| 방송통신 | `KRX시리즈` / `KRX 방송통신` | 유지 | 정확한 KRX 업종 지수 |
| 조선 | 없음 | 제거 | 응답에는 `KRX 조선 TOP10 지수`만 있고 이는 `테마지수`라서 사용하지 않음 |
| 게임 | 없음 | 제거 | 응답에는 `KRX 게임 TOP 10 지수`만 있고 이는 `테마지수`라서 사용하지 않음 |
| 2차전지 | 없음 | 제거 | 응답의 `KRX 2차전지 TOP 10 지수`, `KRX K-AI 2차전지 지수`는 모두 `테마지수`라서 사용하지 않음 |
| 화장품 | 없음 | 제거 | 정확히 대응하는 업종 지수가 응답에 없음 |

## 사용 API

| 공식 API | 엔드포인트 | 앱에서 쓰는 필드 | 용도 |
| --- | --- | --- | --- |
| [금융위원회_지수시세정보](https://www.data.go.kr/data/15094807/openapi.do) | `GetMarketIndexInfoService/getStockMarketIndex` | `basDt`, `idxCsf`, `idxNm`, `clpr`, `vs`, `fltRt` | 지수 카드와 업종 히트맵 |
| [금융위원회_주식시세정보](https://www.data.go.kr/data/15094808/openapi.do) | `GetStockSecuritiesInfoService/getStockPriceInfo` | `basDt`, `srtnCd`, `itmsNm`, `mrktCtg`, `clpr`, `fltRt`, `trPrc` | 시장 열기와 종목 순위 |

두 API는 일 1회 갱신되며 기준일의 다음 영업일 오후에 제공될 수 있다. 따라서 앱은
실시간이라는 표현을 쓰지 않고, 지수와 종목의 기준일 차이를 허용해 각각 표시한다.

## 실패·빈 응답·갱신 지연 처리

- 최신일 탐색과 해당 기준일 전체 조회를 분리하고, 결과가 빈 배열이면 실패로 판정한다.
- 요청마다 8초 제한 시간을 두고, 멈춘 요청도 예시 스냅샷으로 복구한다.
- 필수 KOSPI/KOSDAQ 지수나 8개 업종 지수가 누락되면 불완전한 실제 값을 섞지 않고 예시 스냅샷으로 복구한다.
- 전체 결과 수가 한 페이지 수보다 많으면 일부 데이터로 순위를 만들지 않고 예시 스냅샷으로 복구한다.
- 예시 스냅샷에도 공식 API로 채울 수 없는 장중 스파크라인과 4개 업종 칸은 넣지 않는다.
- 실제 데이터와 예시 데이터는 헤더 배지와 안내문으로 구분한다.
