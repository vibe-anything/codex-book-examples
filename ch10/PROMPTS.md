# 10장 요청문 — 행정 표준 코드로 지역 코드 정확히 찾기

이 폴더는 10장을 **끝낸 직후** 상태다. `ch09`를 복사한 뒤 아래 순서로 만들었다. 실제 API를 부르므로
`.env`에 자기 인증 키가 있어야 한다.

## 1. --search로 코드 규격 찾게 하기 (§10.2)

라이브 웹 검색을 켜고 시작한다.

```bash
codex --search
```

```text
공공데이터포털의 국토교통부 아파트 매매 실거래가 API에서 LAWD_CD와 DEAL_YMD에 각각 어떤 값을 넣어야 하는지 공식 문서에서 찾아줘. 근거가 된 문서 주소도 같이 알려 줘.
```

답과 함께 받은 근거 주소도 직접 연다.

## 2. 다운로드만 사람이 한다 (§10.4)

행정 표준 코드 관리 시스템(`https://www.code.go.kr`)의 자주 이용하는 코드에서 법정동을 고르고,
[법정동 코드 전체자료] 버튼으로 파일을 받는다. 받은 파일을 프로젝트 폴더에 넣는다. 이름은 그대로
둬도 된다. **사람 몫**은 여기까지다.

## 3. @로 파일 붙여 변환 맡기기 (§10.5)

프롬프트에서 `@`를 누르면 피커가 열린다. `@법정동`까지만 쳐도 받은 파일이 잡힌다. File로 표시된 줄을
고른다(`/mention`으로 시작해도 같은 피커가 열린다. 뒤에 경로를 이어 쓰지는 않는다). 마지막 줄이 피커에서
고른 결과다. 이름에 공백이 있어 따옴표가 붙는다.

```text
지역 코드 입력 상자에 코드 대신 지역명을 입력하게 하고, 이 파일로 지역명을 코드로 바꿔 API를 호출하도록 해 줘.
파일 이름은 legalDongCode.txt로 정리하고, 어떤 문자 인코딩인지 먼저 확인한 후 그 인코딩으로 읽어 줘.
법정동 코드 10자리 중 앞 다섯 자리만 LAWD_CD로 쓰고, 폐지여부 열이 ‘존재’인 행만 검색에 써 줘.
서울 강남구를 넣으면 LAWD_CD가 11680이 되는 테스트도 추가해 줘.
"법정동코드 전체자료.txt"
```

이 폴더의 `legalDongCode.txt`가 그 결과다. 파일 인코딩은 EUC-KR이다. 구현이 끝나면 앱을 실행해
서울 강남구를 넣어 본다.

## 4. 입력 규칙 확인하고 AGENTS.md에 남기기 (§10.6)

중구처럼 여러 곳에 있는 이름을 넣으면 오류로 처리한다. 이 폴더를 만든 실행에서는 그 오류 메시지의
후보 이름이 비어 나와, 고치는 방법을 지시하는 대신 화면에 보이는 그대로를 전달했다.

```text
중구를 입력하면 다음 오류가 나와. 지역명이 나와야 하는데 비어 있어.
  지역명이 여러 지역과 일치합니다. 예: , ,
```

확인해서 얻은 처리 기준을 프로젝트 지침에 남긴다.

```text
이번에 확인한 지역명 처리 기준을 AGENTS.md에 정리해 줘.
- 실거래가 API의 조회 단위는 시군구이고, 동 이름은 코드를 찾기 위한 입력으로만 쓴다.
- 폐지여부 열이 ‘존재’인 행만 검색에 쓴다.
- 여러 지역과 일치하는 이름은 임의로 고르지 않고 후보를 보여 준다.
- 법정동 코드 파일의 출처와 다운로드한 날짜
```

`AGENTS.md`의 ‘지역명 처리 기준’과 ‘기준 데이터’ 절이 그 결과다.
