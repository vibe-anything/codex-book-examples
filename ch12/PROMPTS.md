# 12장 요청문 — 실제 데이터까지 완성하기

이 폴더는 12장을 **끝낸 직후** 상태다. `ch12-start`(예시 데이터로 도는 대시보드)를 복사한 뒤,
아래 요청문을 본문 순서대로 codex에 입력해 만들었다. 시작 상태를 직접 만들려면 `ch12-start/PROMPTS.md`의
`/plan` 흐름을 먼저 따른다.

## 1. Git 저장소 만들기 (§12.1)

```text
이 폴더를 Git 저장소로 만들고 첫 커밋을 남겨줘. node_modules처럼 커밋하면 안 되는 것은 빠지게 해줘.
```

## 2. 데이터 조사 맡기기 (§12.2)

```text
지금 구현된 주식 대시보드를 실제 데이터로 채우려면 어떤 공개 데이터가 필요한지 조사해줘.

조건:
- 구현하지 말고 조사만 한다.
- 현재 화면 영역을 기준으로 필요한 데이터와 후보 API를 표로 정리한다.
- 공공데이터포털에서 활용신청할 API 이름과 공식 URL을 남긴다.
- API로 바로 채울 수 있는 칸, 받아 온 값으로 계산해야 하는 칸,
  공개 데이터로 채우기 어려운 칸을 나눠라.
```

## 3. 인증키를 `.env`로 다루게 설정하기 (§12.3)

```text
공공데이터포털 인증키를 이 프로젝트에서 .env로 다루게 설정해줘.
- .env 파일을 만들고, 키를 담을 이름을 `DATA_GO_KR_SERVICE_KEY`로 정한다.
- .gitignore에 .env가 들어 있는지 확인하고, 없으면 추가해 커밋되지 않게 한다.
- 코드는 인증키를 .env에서 읽어 쓰고, 키 값을 코드에 직접 적지 않는다.
- 실제 키 값은 내가 .env에 직접 넣을 테니, 빈 자리만 만들어 줘.
```

요청이 끝나면 **사람이 직접** `.env`의 등호 뒤에 발급받은 인증키를 붙여 넣는다.

## 4. API 하나가 호출되는지 확인하기 (§12.4)

```text
.env의 DATA_GO_KR_SERVICE_KEY를 써서 공공데이터포털 주식시세정보 API를 한 번 호출해줘.
종목명은 삼성전자, 응답은 JSON으로 받아줘.
응답에서 종가, 등락률, 거래대금, 시장구분 필드 이름과 값의 단위를 표로 정리해줘.
코드는 아직 고치지 말고, 호출 결과만 보여줘.
```

## 5. `/goal`로 수집을 끝까지 끌고 가기 (§12.6)

```text
/goal 목표: 지금 주식 대시보드를 공공데이터포털에서 가져올 수 있는 실제 데이터로 채운다.

완료 조건(이걸 다 만족해야 끝):
- 업종 히트맵은 지수시세정보의 KRX 시리즈 업종 지수로만 채운다. 테마·규모 지수나
  종목 합산 계산은 쓰지 않는다.
- 12개 업종 목록은 그대로 두고, 실제 값이 있는 칸만 화면에 남긴다. 뺀 칸은 왜 못
  채우는지 보고에 남긴다.
- 화면 구조와, 데이터를 못 받았을 때 예시 데이터로 돌아가는 안전장치는 바꾸지 않는다.
- 끝나면 유지한 칸, 뺀 칸, 쓴 API를 표로 보고한다.

각 API는 확인에 필요한 만큼만 호출하고, 마지막에 테스트나 빌드를 실행한다.
```

이 폴더를 만든 실행에서는 같은 목표를 더 길게 풀어 쓴 요청문을 썼다. 결과는 같고, 위 요청문이
원고에 실린 판이다.

완료 보고를 완료 조건과 대조하고, 어긋난 항목이 있으면 무엇이 다른지 짚어 되돌려 준다
(§12.7). 이 폴더를 만든 실행에서는 제외 대상 네 업종이 "값 없음" 타일로 남아 있어,
화면에서 빼 달라는 후속 요청 한 번으로 여덟 칸 상태를 만들었다.
