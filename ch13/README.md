# 13장 완료 상태: 실제 데이터로 도는 주식 대시보드

이 폴더는 13장을 끝낸 상태다. 시작 상태는 같은 저장소의 `ch13-start`다.

공공데이터포털의 금융위원회 지수시세정보·주식시세정보 API로 대시보드를 실제 데이터로 채운다.

업종 히트맵은 12개 업종 목록을 코드에 보존하되, 정확한 KRX 업종 지수가 있는 8개만 화면에 그린다. 그릴 수 없는 조선·게임·2차전지·화장품의 이유는 `API_CHECK.md`에 정리되어 있다.

외부 API가 실패하거나 빈 응답을 반환하거나 갱신이 지연되면 예시 데이터로 화면을 유지한다. 화면 배지로 실제 데이터와 예시 데이터를 구분한다.

데이터는 실시간이 아니며, 영업일 기준 다음 날 오후에 갱신된다.

## 실행 방법

먼저 `.env`를 만들고 `DATA_GO_KR_SERVICE_KEY`에 공공데이터포털 인증키를 넣는다.

```bash
npm install
npm run dev
```

생성 환경: codex-cli 0.146.0, 2026-08-02.
