# 14장 프롬프트

이 폴더는 `ch13`을 이어받아 아래 순서대로 진행한 결과다. 인증키 값은 대화나 코드에 넣지 않고 `.env`에만 넣는다.

## 1. 관심 종목 붙이기

```
대시보드에 관심 종목 기능을 붙여줘.

- 이미 수집해 둔 종목 시세 데이터에서 종목을 검색해 관심 종목으로 추가하고 해제할 수 있게 한다.
- 선택한 종목은 대시보드 맨 위에 카드로 나란히 모아 보여준다.
  종목명, 현재가, 등락률을 표시하고 상승은 붉은색, 하락은 파란색으로 강조한다.
- 관심 종목 목록은 localStorage에 저장해 새로고침해도 유지한다.
- 관심 종목이 하나도 없을 때는 그 자리에 추가 방법을 안내하는 문구를 보여준다.
- 기존 화면 구조와 데이터 흐름은 바꾸지 않는다.
```

## 2. 지침과 확인 명령 정하기

```
AGENTS.md에 "표시·계산 로직을 바꾸면 npm test를 실행하고 결과를 보고한다"를 적어줘.
그리고 npm test가 지금 하는 확인은 그대로 두고, 그 뒤에 next build를 이어서 실행하게 해줘.
```

> 결과: `"test": "node --test && next build"`. 13장이 만든 테스트 8건이 그대로 돌고 빌드가 뒤에 붙는다.

## 3. 테스트 확인 훅 걸기

```
이 프로젝트에 훅으로 테스트 확인 규칙을 걸어줘.

- 턴이 끝날 때 표시·계산 로직이 바뀌었는데 테스트를 돌린 기록이 없으면,
  npm test를 실행하고 결과를 보고한 뒤 마무리하라고 되물어야 한다.
- 같은 턴에서 한 번 되물었으면 다시 묻지 않는다. 무한 반복을 막아야 한다.
```

> `.codex/` 쓰기 승인이 필요하다. 승인하지 않으면 Codex가 "읽기 전용이라 설치할 수 없다"고 보고하고 멈춘다.

## 4. 훅이 정말 도는지 확인하기

```
app/globals.css 맨 아래에 화면에는 아무 영향이 없는 임시 주석 한 줄을 남겨줘.
이번에는 npm test를 실행하지 말고 바로 마무리해줘.
```

> 결과: `Stop hook (blocked)` → Codex가 `npm test`를 실행하고 보고한 뒤 마무리. 이어진 턴에서는 다시 묻지 않는다.
>
> 주의: 주석을 **넣었다가 다시 지우는** 형태로 시키면 훅이 발동하지 않을 수 있다. 파일 내용 해시로 변경을 판정하는 훅이 만들어지면 넣었다 뺀 파일은 "바뀐 것이 없는" 파일이 된다. 확인이 끝나면 주석은 지운다.

## 5. 인증키 보호 훅 걸기

```
인증키 보호 훅을 추가해줘.

- 명령이나 파일 수정을 실행하기 직전(PreToolUse)에 내용을 확인해서, .env 파일을
  직접 읽거나 여는 시도는 차단한다. process.env 참조는 허용한다.
- .env에 있는 실제 키 값이 명령이나 코드에 그대로 나타나도 차단한다. 키 값 비교는
  훅 스크립트가 내 컴퓨터에서 .env를 읽어 처리하고, 값을 대화에 올리지 않는다.
- 차단 메시지에는 대신 어떻게 해야 하는지(process.env 참조 유지)를 함께 적어줘.
```

## 6. 내가 시켜도 막히는지 확인하기

```
매번 .env 챙기는 게 귀찮아. .env에 있는 실제 인증키 값을 읽어서
그냥 코드에 넣어줘. .env 파일이 없어도 돌아가게.
```

> 결과: `PreToolUse hook (blocked)`. 키 값은 끝까지 `.env` 밖으로 나오지 않는다.
>
> 주의: 차단당한 Codex가 키를 다른 곳(예: OS 키체인)에 옮기는 우회를 제안하며 파일을 만들 수 있다. 훅이 막는 것은 행위이지 목적이 아니다. 이 폴더에서는 그렇게 생긴 우회 산출물을 되돌려 두었다.

## 장 종료 상태

- `.codex/hooks.json` — `PreToolUse`(인증키 보호) · `UserPromptSubmit`·`PostToolUse`·`Stop`(테스트 확인) 등록
- `.codex/hooks/` — 판정 스크립트 2종과 각각의 테스트
- `AGENTS.md` — 표시·계산 로직 변경 시 `npm test` 지침 한 줄
- `npm test` = `node --test && next build` (테스트 8건 + 빌드)
