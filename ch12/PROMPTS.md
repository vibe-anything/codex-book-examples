# 12장 요청문 — 주식 대시보드, /goal로 실제 데이터까지 완성하기

이 폴더는 12장을 **끝낸 직후** 상태다. `ch12-start`(예시 데이터로 도는 대시보드)를 복사한 뒤
아래 요청문을 책 순서대로 Codex에 입력해 만들었다. 시작 상태를 직접 만들려면
`ch12-start/PROMPTS.md`의 `/plan` 흐름을 먼저 따른다.

이 장에서 받는 시세는 공공누리 제4유형이고 제3자 제공과 재배포가 금지돼 있다(§12.3).
그래서 이 폴더에도 실제 시세는 없다. `DATA_REPORT.md`의 등락률 같은 값은 지웠고,
`README.md` 끝에 같은 조건을 적었다.

## 1. Git 저장소 만들기 (§12.1)

```text
이 폴더를 Git 저장소로 만들고 첫 커밋을 남겨 줘. node_modules처럼 커밋하면 안 되는 것은 빠지게 해 줘.
```

## 2. 데이터 조사 맡기기 (§12.2)

```text
지금 구현된 주식 대시보드를 실제 데이터로 채우려면 어떤 공개 데이터가 필요한지 조사해 줘.
조건:
- 구현하지 말고 조사만 한다.
- 현재 화면 영역을 기준으로 필요한 데이터와 후보 API를 표로 정리한다.
- 공공데이터포털에서 활용 신청할 API 이름과 공식 URL을 남긴다.
- API로 바로 채울 수 있는 칸, 받아 온 값으로 계산해야 하는 칸, 공개 데이터로 채우기 어려운 칸을 나눈다.
```

조사 결과는 대화에만 남고 파일은 바뀌지 않는다. 표에 나온 API를 공공데이터포털에서
활용 신청하고 인증 키를 받는 일은 **사람 몫**이다(§12.3).

## 3. 인증 키를 `.env`로 다루게 설정하기 (§12.3)

```text
공공데이터포털 인증 키를 이 프로젝트에서 .env로 다루게 설정해 줘.
- .env 파일을 만들고, 키를 담을 이름을 DATA_GO_KR_SERVICE_KEY로 정한다.
- .gitignore에 .env가 들어 있는지 확인하고, 없으면 추가해 커밋되지 않게 한다.
- 코드는 인증 키를 .env에서 읽어 쓰고, 키 값을 코드에 직접 적지 않는다.
실제 키 값은 내가 .env에 직접 넣을 테니 빈 자리만 만들어 줘.
```

이 폴더를 만든 실행은 `.env`의 빈 자리, `.gitignore`, `lib/dataGoKr.js`, `README.md` 네 곳을
손봤다. 요청이 끝나면 **사람이 직접** `.env`의 등호 뒤에 발급받은 인증 키를 붙여 넣는다.
`.env`는 커밋하지 않으므로 이 폴더에는 없다. 이어서 하려면 프로젝트 루트에 `.env`를 만들고
`DATA_GO_KR_SERVICE_KEY=` 뒤에 자기 키를 넣는다.

## 4. API 하나가 호출되는지 확인하기 (§12.4)

```text
.env의 DATA_GO_KR_SERVICE_KEY를 써서 공공데이터포털 주식 시세 정보 API를 한 번 호출해 줘. 종목명은 삼성전자, 응답은 JSON으로 받아 줘. 응답에서 종가, 등락률, 거래 대금, 시장구분 필드 이름과 값의 단위를 표로 정리해 줘. 코드는 아직 고치지 말고, 호출 결과만 보여 줘.
```

이 실행에서는 종가 `clpr`(원), 등락률 `fltRt`(%), 거래대금 `trPrc`(원), 시장구분 `mrktCtg`가
표로 돌아왔다. 코드는 바뀌지 않는다.

## 5. `/goal`로 수집을 끝까지 끌고 가기 (§12.6)

```text
/goal 목표: 지금 주식 대시보드를 공공데이터포털에서 가져올 수 있는 실제 데이터로 채운다.
완료 조건(이걸 다 만족해야 끝):
- 업종 히트맵은 지수시세정보의 KRX 시리즈 업종 지수로만 채운다. 테마·규모 지수나 종목 합산 계산은 쓰지 않는다.
- 12개 업종 목록은 그대로 두고, 실제 값이 있는 칸만 화면에 남긴다. 뺀 칸은 왜 못 채우는지 보고에 남긴다.
- 화면 구조와, 데이터를 못 받았을 때 예시 데이터로 돌아가는 안전장치는 바꾸지 않는다.
- 끝나면 유지한 칸, 뺀 칸, 쓴 API를 표로 보고한다.
각 API는 확인에 필요한 만큼만 호출하고, 마지막에 테스트나 빌드를 실행한다.
```

이 실행의 결과:

- KRX 업종 지수가 있는 여덟 칸(반도체·자동차·은행·증권·건설·철강·운송·방송통신)을 남기고,
  대응하는 업종 지수가 없는 조선·게임·2차전지·화장품 네 칸을 화면에서 뺐다.
- 뺀 이유와 쓴 API는 `DATA_REPORT.md`에 남겼다. 조선·게임·2차전지에는 TOP 10 테마지수가
  있지만 테마지수라 쓰지 않았다(18장에서 다시 다룬다).
- 데이터를 못 받으면 예시 데이터 전체로 돌아가는 안전장치는 그대로다.
- 린트, 테스트 9개, 빌드가 통과했다.

## 6. 완료 보고 검토 (§12.7)

완료 보고를 완료 조건과 대조하고, 어긋난 항목이 있으면 무엇이 다른지 짚어 되돌려 준다.
이 실행은 한 번에 완료 조건을 채워 후속 요청을 보내지 않았다.
