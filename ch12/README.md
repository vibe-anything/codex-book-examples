# 공공데이터로 동작하는 국내 주식 대시보드

금융위원회의 공공데이터포털 주식시세정보와 지수시세정보를 읽어 최근 공개된
거래일의 시장을 보여 준다. 공공데이터는 실시간 시세가 아니며, 기준 거래일 다음
영업일 오후 1시 이후 갱신될 수 있다.

```bash
npm install
npm run dev
```

공공데이터포털 인증키는 프로젝트 루트의 `.env`에 입력한다.

```dotenv
DATA_GO_KR_SERVICE_KEY=
```

키는 서버 코드에서 `getDataGoKrServiceKey()`로 읽으며, 소스 코드에 직접 적거나
`NEXT_PUBLIC_` 접두사를 붙이지 않는다.

## 사용 API

| 공공데이터포털 API | 사용 오퍼레이션 | 화면에서 쓰는 값 |
| --- | --- | --- |
| [금융위원회_주식시세정보](https://www.data.go.kr/data/15094808/openapi.do) | `getStockPriceInfo` | KOSPI·KOSDAQ 종목의 종가·등락률·거래대금 |
| [금융위원회_지수시세정보](https://www.data.go.kr/data/15094807/openapi.do) | `getStockMarketIndex` | KOSPI·KOSDAQ 및 KRX시리즈 업종 지수의 종가·전일 대비·등락률 |

## 화면별 데이터

| 화면 | 데이터 | 처리 방식 |
| --- | --- | --- |
| KOSPI·KOSDAQ 카드 | 종가, 전일 대비, 등락률, 최근 거래일 종가 흐름 | 지수시세정보의 코스피·코스닥 응답 |
| 시장 열기 | 3% 이상 상승 종목 비율 | KOSPI·KOSDAQ 종목의 등락률로 계산 |
| 업종 히트맵 | 8개 업종 등락률 | 지수시세정보의 정확한 KRX 업종 지수 |
| 종목 순위 | 상승률·하락률·거래대금 상위 5개 | 최신 주식시세를 정렬해 계산 |

업종 목록 12개는 코드에 그대로 유지한다. 최신 지수시세정보의 `KRX시리즈`에서
정확히 대응하는 업종 지수를 확인한 결과는 다음과 같다. 대응 지수가 없는 네 업종은
테마·규모 지수로 대신하거나 종목 시세를 합산하지 않고, 해당 타일만 렌더링하지 않는다.

| 화면 업종 | KRX시리즈 업종 지수 | 화면 표시 |
| --- | --- | --- |
| 반도체 | KRX 반도체 | 유지 |
| 자동차 | KRX 자동차 | 유지 |
| 은행 | KRX 은행 | 유지 |
| 증권 | KRX 증권 | 유지 |
| 건설 | KRX 건설 | 유지 |
| 철강 | KRX 철강 | 유지 |
| 운송 | KRX 운송 | 유지 |
| 방송통신 | KRX 방송통신 | 유지 |
| 조선 | 정확히 대응하는 지수 없음 | 제외 |
| 게임 | 정확히 대응하는 지수 없음 | 제외 |
| 2차전지 | 정확히 대응하는 지수 없음 | 제외 |
| 화장품 | 정확히 대응하는 지수 없음 | 제외 |

공공 API 호출 실패, 빈 응답, 두 API의 기준일 불일치, 7일을 넘긴 오래된 응답에는
`data/marketSnapshot.js`의 예시 데이터로 돌아간다.

지수 카드의 미니 차트는 같은 지수시세정보 응답에서 모은 최근 거래일 종가를 잇는다.
공개 API에 장중 시계열이 없어 장중 흐름은 그리지 않으며, 응답에 거래일이 하나뿐이면
그 미니 차트만 비우고 나머지 화면은 실데이터로 그린다.
