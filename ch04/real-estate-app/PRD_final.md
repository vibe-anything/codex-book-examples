# 실거래가 조회 앱 PRD 최종안

## 목적

서울 강남구의 특정 계약월 아파트 매매 실거래가를 빠르게 확인한다.

## 첫 범위

- 서울 강남구의 한 계약월만 다룬다.
- 이번 장에서는 PRD와 작업 계획까지만 만들고, 실제 API 호출은 8장에서 다룬다.

## 개발 방식

- 정적 웹 단독 방식이 아니라 서버 방식으로 개발한다.
- 브라우저는 자체 서버의 조회 API만 호출한다.
- 공공데이터 API 키는 서버 환경변수로 관리하고, 브라우저에 노출하지 않는다.
- 서버는 이후 실제 공공데이터 API 호출을 연결할 수 있도록 조회 API 경계를 제공한다.

## 입력값

- 지역 코드, 계약년월, 페이지 번호, 한 번에 가져올 행 수

## 화면 구성

- 상단에 지역 선택, 계약년월 입력, 조회 버튼을 둔다.
- 그 아래에 조회 지역, 계약월, 거래 건수를 요약한다.
- 거래 목록은 카드가 아니라 표로 시작한다.

## 표시 필드

- 단지명, 법정동, 거래금액, 전용면적, 층, 계약일, 건축년도

## 확인할 상태

- 거래 있음, 거래 없음, API 키 없음, API 호출 실패를 서로 다른 메시지로 보여준다.

## 이번 장에서 하지 않을 것

- API 키 발급, 실제 공공데이터 API 호출
- 여러 달 비교, 지도, 차트, 즐겨찾기
- 자동 수집, 알림

## 완료 기준

- 작업 계획에 화면 구성, 조회 조건, 데이터 흐름, 오류 처리, 제외 범위가 들어 있다.
- 작업 계획에 서버 방식 개발 조건과 API 키 비노출 조건이 들어 있다.
- 구현 전에 사람이 계획을 읽고 범위를 조정한다.
