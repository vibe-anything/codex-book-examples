# 14장 요청문 — 주식 시세 쌓을 데이터베이스, MCP로 연결해 만들기

이 폴더는 14장을 **끝낸 직후** 상태다. `ch13`을 복사한 뒤 아래 순서로 만들었다.
Supabase 가입·프로젝트 준비, MCP 연결 두 줄, `.env`·`.env.sample` 작성은 **사람 몫**이다.

## 0. 사람 몫 준비 (§14.3)

- Supabase 프로젝트 준비 후 Connect에서 URL·publishable key 확인.
- 터미널에서 두 줄 (Supabase 공식 안내에서 복사):

```bash
codex mcp add supabase --url "https://mcp.supabase.com/mcp?project_ref=<프로젝트 ID>"
codex mcp login supabase
```

- `.env`에 `NEXT_PUBLIC_SUPABASE_URL`·`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` 직접 기입.
- `.env.sample`을 직접 만들어 이름 세 개만 남기고 값은 비운다. `.gitignore`가 `.env.*`로
  견본까지 막으면 `!.env.sample` 한 줄을 더한다.

## 1. 테이블 설계 (§14.4)

```text
대시보드 데이터를 Supabase에 저장하려고 해. 테이블 구조를 설계해줘.

요구사항:
- 일별 시세: 종목코드, 종목명, 기준일, 종가, 등락률, 거래대금을 저장한다.
  같은 기준일의 같은 종목이 두 번 저장되는 일은 구조로 막아야 한다.
- 앱에서는 익명 방문자가 시세를 읽기만 할 수 있게 RLS를 켜고 읽기(SELECT) 정책만 만든다.
- 쓰기(INSERT, UPDATE, DELETE) 정책은 만들지 않는다. 시세 적재는 이 학습용 MCP로만 한다.
- 관심 종목은 localStorage에 남긴다. 사용자 계정과 관심 종목 테이블은 만들지 않는다.
- 아직 만들지 말고, 테이블 구조와 그렇게 정한 이유부터 보여줘.
```

구조를 검토하고 맞으면 만들게 한다(변경 도구 호출마다 승인 창이 뜬다).

## 2. 적재와 이중 적재 실험 (§14.4)

```text
오늘 수집한 시세를 방금 만든 일별 시세 테이블에 적재해줘.
시세는 12장부터 쓰던 수집 코드로 공공데이터포털에서 받은 실제 값이어야 하고,
임의로 만든 값을 넣으면 안 돼. 끝나면 행이 몇 개인지 알려줘.
그다음 같은 데이터를 한 번 더 적재하고, 행 수가 어떻게 됐는지 다시 알려줘.
```

두 번째 적재 뒤에도 행 수가 그대로면 성공이다(이 폴더를 만든 실행: 2,764 → 2,764).

## 3. 화면을 데이터베이스에서 읽게 하기 (§14.5)

```text
이제 대시보드가 Supabase를 읽게 바꾸자.
- 관심 종목은 지금처럼 localStorage에서만 읽고 써줘.
- 시세는 앞에서 만든 일별 시세 테이블의 최신 기준일 데이터를 읽어 보여주고,
  그 기준일을 화면에 함께 표시해줘.
- NEXT_PUBLIC_SUPABASE_URL과 NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY를 사용해.
- 앱에는 시세를 추가·수정·삭제하는 경로를 만들지 마.
- Supabase에 데이터가 없거나 읽기에 실패하면 기존 API를 호출하고,
  그것도 실패할 때만 예시 데이터와 안내를 보여줘.
```

이 폴더를 만든 실행은 Supabase에 없는 지수·업종 영역을 화면에서 숨겼다. 다음 한 줄로
네 영역을 복원했다(전환 후 점검과 함께 확인).

```text
지수 카드, 시장 열기, 업종 히트맵은 Supabase에 없더라도 지금처럼 기존 API 경로로 계속 채워줘.
Supabase에서 읽는 것은 종목 시세만이야. 화면 네 영역 구조는 그대로 유지해줘.
```

## 4. 전환 후 점검 (§14.5)

본문 체크리스트 다섯 가지를 확인한다. 마지막 항목은 Codex에게 시켜도 된다:

```text
전환 후 점검 마지막 항목이야. 시세 테이블에 앱이 쓰는 publishable key 경로로 쓰기(INSERT)를
한 번 시도해서 RLS가 거부하는지 확인해줘. MCP 말고 앱 키 경로로만 시험해.
거부되는 게 정상이야. 결과만 알려줘.
```

끝나면 MCP 주소에 `&read_only=true`를 붙여 잠그고 `codex mcp login supabase`로 다시
로그인한다(주소가 바뀌면 로그인이 풀린다).
