# 8장 요청문 — API 문서 읽고 실거래가 화면까지 만들기

이 폴더는 8장을 **끝낸 직후** 상태다. `ch07`을 복사한 뒤 아래 순서로 만들었다. 8장부터는 실제
공공 데이터 API를 부르므로 `.env`에 자기 인증 키가 있어야 한다. 키는 이 폴더에 없다.

## 1. 활용 신청과 인증 키 (§8.2~8.3)

공공데이터포털에서 국토교통부 아파트 매매 실거래가 API를 활용 신청하고, 개발 계정에서 엔드포인트와
일반 인증 키를 확인한다. **사람 몫**이다.

## 2. .env에 인증 키 보관하기 (§8.4)

프로젝트 폴더에 `.env`를 만들고 키를 넣는다. 직접 만들기 번거로우면 Codex에 맡기고 값만 직접
채운다.

```text
프로젝트 루트에 .env 파일을 만들고 PUBLIC_DATA_SERVICE_KEY 항목을 비워 둬.
```

```dotenv
PUBLIC_DATA_SERVICE_KEY=발급받은_키를_여기에_넣기
```

프로젝트 루트의 `.gitignore`에 다음 줄이 있는지 확인하고, 없으면 추가한다(파일이 없으면 새로 만든다).

```gitignore
.env
```

## 3. .env의 키로 첫 호출 확인하기 (§8.5)

```text
아래 API를 .env의 PUBLIC_DATA_SERVICE_KEY로 한 번 호출해 줘.
https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade
- LAWD_CD는 11110, DEAL_YMD는 202607
- 성공 여부와 거래 건수를 알려 주고, 첫 거래 한 건은 XML 태그 그대로 보여 줘.
- 키가 들어간 전체 URL은 화면에 출력하지 마.
```

## 4. 문서 주소를 주고 구현 맡기기 (§8.6)

```text
방금 확인한 내용을 API.md에 반영해 줘.
엔드포인트와 요청 변수, 응답 예시 한 건, 확인한 날짜를 남겨 줘.
키는 넣지 마.
```

```text
아래 공공 데이터 API 문서 페이지를 참고해 현재 프로젝트에 연동해 줘.
https://www.data.go.kr/data/15126469/openapi.do
```

구현이 끝나면 실행하기 전에 바뀐 범위를 본다.

```text
/diff
```

Codex가 앱을 실행하지 않았다면 직접 실행한다. Codex CLI 안에서는 `!npm run dev`처럼 입력해도 된다.

```sh
# 의존성 설치
npm install
# 실행
npm run dev
```

7장에서 띄운 앱이 아직 떠 있으면 3000번 포트가 사용 중일 수 있다. 어느 터미널에서 실행했는지
모르겠다면 이렇게 맡긴다.

```text
이 프로젝트에서 실행 중인 로컬 서버를 찾아 안전하게 종료해 줘. 종료할 프로세스와 이유를 먼저 보여 줘.
```

`.env`의 키에서 한 글자를 지워 일부러 틀리게 만든 뒤 앱을 새로 고쳐 본다. 목록이 그대로 나오면
샘플 데이터로 대체하는 코드가 남아 있는 것이다.

```text
API 호출이 실패해도 목록이 나와. 샘플 데이터로 대체하는 코드가 남아 있으면 제거하고, 호출이 실패하면 화면에 오류 메시지를 보여 줘.
```

## 5. 상세 화면 맡기고 응답과 대조하기 (§8.7)

```text
실거래가 목록 아이템을 클릭하면 상세 화면으로 이동하게 해 줘.
상세 화면에서는 선택한 거래의 XML 응답에 포함된 모든 필드를 key-value 형태로 빠짐없이 보여 줘.
```

```text
API.md에 남긴 응답 예시와 지금 상세 화면에 표시되는 키를 대조해 줘. 문서에는 있는데 화면에 없는 키, 화면에는 있는데 문서에 없는 키를 각각 알려 줘.
```

```text
방금 확인한 실제 응답과 AGENTS.md의 데이터 처리 규칙을 대조해 줘. 실제 응답과 맞지 않는 규칙이 있으면 알려 줘.
```

## 6. 필드 뜻을 공식 문서로 못 박기 (§8.8)

```text
다음 링크의 Swagger UI Model 설명을 기준으로 필드 라벨을 한글로 매핑해 줘. 매핑한 라벨과 원본 키, 근거를 API.md에도 남겨 줘.
https://www.data.go.kr/data/15126469/openapi.do#/API%20%EB%AA%A9%EB%A1%9D/getRTMSDataSvcAptTrade
```

문서 페이지의 HWP 기술 문서를 쓰려면 프로젝트 폴더에 다운로드해 Codex 터미널에 끌어다 놓거나,
`/mention`을 입력해 나타나는 파일 목록에서 HWP 파일을 고른 뒤 같은 요청을 한다. 이때는 라벨이
HWP 응답 명세의 국문 항목명을 따라, 이 폴더(Swagger 기준)의 라벨과 표기가 조금 다를 수 있다.
