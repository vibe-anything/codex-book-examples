# codex-book-examples

이 저장소는 「Codex로 하는 바이브 코딩」의 예제 저장소로, AI 코딩 에이전트에 입력한 요청문과 그 결과물을 장별로 보관한다.

## 구성 원칙

- 각 장별로 폴더를 구성한다. `chNN` 폴더는 **그 장을 마친 상태**다. 중간 장부터 실습하려면 앞 장 폴더에서 시작한다. 예를 들어 8장을 실습하려면 `ch07`을 내려받는다. 장마다 받을 폴더는 아래 표에 있다.
- 2부(4~11장)는 아파트 실거래가 앱, 3부(12~18장)는 주식 대시보드다. 서로 다른 프로젝트이므로 코드를 이어받지 않는다.
- 4장은 버리는 실험과 이후 장으로 이어지는 본선을 나누어 `real-estate-quick`과 `real-estate-app` 두 폴더를 둔다. 5장은 `real-estate-app`을 이어받는다.
- 6장은 앱 코드를 바꾸지 않고 5장에서 만든 `AGENTS.md`에 답변 방식 한 줄만 더한다. `ch06`은 `ch05`에 그 한 줄을 더한 상태다.
- 12장은 `/plan`으로 세운 예시 데이터 대시보드에서 출발하므로 그 시작 상태를 `ch12-start`에 따로 둔다. `ch12`는 12장을 마친 상태다.
- 각 폴더마다 그 장에서 입력한 요청문을 정리한 `PROMPTS.md`를 둔다. 요청문은 책과 같은 순서, 같은 글자로 옮긴다. 책에 요청 상자가 없는 단계는 그 폴더를 만든 실행이 보낸 문장을 적고, 그렇다고 밝힌다.
- 이 저장소는 장별 폴더를 파일로만 담는다. 각 장에서 만든 Git 이력은 함께 배포되지 않는다. 중간 장부터 시작한다면 폴더를 복사한 뒤 먼저 Git 저장소로 만들고 첫 커밋을 남긴다. 12장처럼 Codex에게 “이 폴더를 Git 저장소로 만들고 첫 커밋을 남겨 줘. node_modules처럼 커밋하면 안 되는 것은 빠지게 해 줘.”라고 요청하면 된다. 7·8장의 `/diff`, 11장의 되돌리기, 13장부터의 훅, 15장의 푸시, 17장의 깃 워크트리가 Git을 쓴다.
- 13장부터의 폴더에 든 훅(`.codex/hooks.json`)은 그 폴더가 Git 저장소의 맨 위 폴더일 때 동작한다. 이 저장소를 클론한 자리에서 장 폴더를 바로 열지 말고, 폴더를 복사해 따로 Git 저장소로 만든 뒤 그 폴더에서 Codex를 연다. 처음 열면 훅을 검토하라는 안내가 뜨니 정의를 읽고 신뢰한다.
- 실제 API 키는 어떤 폴더에도 두지 않는다. `.env`는 커밋하지 않고 견본만 남긴다. 2부는 `.env.example`, 3부는 책 표기에 맞춰 `.env.sample`을 쓴다(3부 견본은 14장부터 있다. 12·13장은 README에 키 이름을 적었다).

## 실행 결과가 다를 때

같은 요청도 실행마다 결과가 다르다. 각 폴더의 `PROMPTS.md`에 그 폴더를 만든 실행의 결과를 적어 두었다.

- 2부 폴더는 책의 그림을 찍기 전에 만든 실행의 결과다. 책의 그림은 이 폴더들을 복사해 다시 찍었으므로, 화면 속 문장이나 파일 구성이 이 폴더와 조금 다를 수 있다. `ch04/real-estate-quick`만 책의 그림을 찍은 실행 그대로다.
- 3부 폴더(`ch12`~`ch18`)는 책의 그림을 찍은 실행의 장별 결과다.

## 데이터와 이용 조건

- 2부의 국토교통부 아파트 매매 실거래가 API는 공공데이터포털에 이용허락범위 제한 없음으로 안내돼 있다. 4~7장의 거래 목록은 화면을 먼저 완성하려고 넣은 연습용 데이터이고, 8장부터는 각자의 인증 키로 실제 API를 부른다. 저장소에 API 응답을 저장해 두지는 않았다.
- `ch10`·`ch11`의 `legalDongCode.txt`는 행정 표준 코드 관리 시스템에서 받은 법정동 코드 전체자료다. 같은 법정동 코드는 공공데이터포털에서도 이용허락범위 제한 없이 제공된다.
- 3부의 금융위원회 시세 API(주식시세정보, 지수시세정보 등)는 공공데이터포털 상세 페이지의 이용허락범위가 공공누리 제4유형이고, 제3자 제공과 재배포를 금지한다. 그래서 이 저장소에는 실제 시세를 두지 않는다. `data/marketSnapshot.js`는 예시 값이고, `DATA_REPORT.md`에 실행이 적어 둔 실제 값은 지웠다. 인증 키는 각자 받는다. 배포하면 15장대로 주소를 Vercel 계정으로 로그인해야 열리게 잠근다.
