# 국내 주식 시장 대시보드 완료 기준

이 파일은 `korea-market-dashboard` 앱에만 적용한다. 검증 때 저장소의 현재 코드와 계약 문서가 달라졌다면 현재 내용을 우선 확인하고 차이를 보고한다.

## 앱과 경로

- 앱 식별자: 루트 `package.json`의 `name`이 `korea-market-dashboard`
- 배포 화면: 최신 프로덕션 배포의 `/`
- 별도 공개 API 라우트: 없음. `/`의 서버 렌더링 과정에서 Supabase와 금융위원회 공공데이터포털을 조회함.
- 앱 기준 문서: 루트 `README.md`
- 환경변수 샘플 계약: 루트 `.env.sample`

## 배포 화면 완료 기준

다음을 모두 확인해야 PASS로 판정한다.

1. 루트 주소가 성공 응답을 반환하고 `시장 한눈에 보기` 제목을 표시한다.
2. 데이터 출처 배지가 `Supabase`, `Supabase + 공공데이터`, `공공데이터` 중 하나다.
3. 출처나 안내 문구에 `예시 데이터`, 외부 데이터 조회 실패 또는 실제 시세를 대신한 fallback이 나타나지 않는다. `Supabase + 예시 데이터`도 실패다.
4. 화면 상단에 `YYYY.MM.DD 종가 기준` 형태의 기준일이 보이고, 서울 기준 검증일과 7일 넘게 차이 나지 않는다.
5. KOSPI와 KOSDAQ 카드에 유한한 지수 값, 전일 대비, 등락률이 표시된다.
6. 시장 열기에 유한한 퍼센트 값이 표시된다.
7. 업종 히트맵에는 실제 지수가 있는 `반도체·자동차·은행·증권·건설·철강·운송·방송통신` 8개 타일의 유한한 등락률이 표시된다. 데이터가 없는 `조선·게임·2차전지·화장품`은 완료 판단에 포함하지 않는다.
8. `상승률 상위`, `하락률 상위`, `거래대금 상위` 표가 각각 5개 종목을 표시하고 종목명·가격·등락률이 비어 있거나 `NaN`이 아니다. 거래대금 표에는 거래대금도 표시된다.
9. 데이터 안내 또는 하단 고지에서 Supabase 종목 시세와 금융위원회 공공데이터 중 실제 사용한 출처를 식별할 수 있다.

관심 종목은 브라우저 `localStorage`에 따라 달라지므로 비어 있다는 이유만으로 실패 처리하지 않는다. 실제 시세 여부는 서버 렌더링되는 지수와 순위 표로 판단한다.

## 환경변수 계약 기준

검증 시 코드, `.env.sample`, `README.md`를 다시 읽어 이름 집합을 비교한다. 현재 기준 이름은 다음과 같다.

- `DATA_GO_KR_SERVICE_KEY`
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

값, 설정 여부, Vercel에 저장된 값은 조회하지 않는다. 이 목록은 변경 감지용 기준이며 실제 저장소 문서를 대신하지 않는다.
