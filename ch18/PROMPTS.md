# 18장 요청문 — 다음 세션도, 다음 사람도 이어받게 만들기

이 폴더는 18장을 **끝낸 직후** 상태다. `ch17`(종목 비교·다크 모드까지 합친 상태)을
복사한 뒤 아래 순서로 만들었다.

## 1. before 실험 — 새 세션은 남이다 (§18.1)

`/new`(또는 새 세션)에서 결정 기록 없이 부탁한다.

```text
업종 히트맵에 빠져 있는 업종들이 있네. 채워줄 수 있어?
```

이 폴더를 만든 실행의 결과: **히트맵을 8칸에서 16칸으로 늘렸다.** 12장에서 못 박은
12업종 목록 대신 보험·경기소비재·기계장비·에너지화학·유틸리티·정보기술·필수소비재·
헬스케어를 새로 넣고, 배열도 4×4로 바꿨다. 테스트 27개와 프로덕션 빌드는 그대로 통과했다.
(0.145 실행에서는 화장품을 임의 산식으로 채웠다 — 모양은 달라도 "어제의 결정을 모른다"는
같다.)

되돌린다:

```text
방금 이 대화에서 만든 변경을 전부 되돌려줘. 커밋하지 않은 변경만 대상이고,
되돌리기 전에 어떤 파일을 어떻게 되돌릴지 먼저 보여줘.
```

## 2. 인수인계 문서 작성 (§18.3)

원래 대화로 돌아와(`/resume`) 오늘의 세션에게 문서를 쓰게 한다. 요청문은 본문 §18.3의
긴 블록을 그대로 쓴다(README에는 이유와 사용법, AGENTS.md에는 명령과 금지).
이 실행은 README.md·AGENTS.md를 갱신하고 `.env.sample`은 이미 정확하다며 두었다(8분 35초).

## 3. after 재실험 (§18.4)

Codex를 **완전히 종료**하고 프로젝트 폴더에서 다시 연 뒤, 처음과 똑같이 부탁한다.

```text
업종 히트맵에 빠져 있는 업종들이 있네. 채워줄 수 있어?
```

이 실행의 결과: AGENTS.md → README 순으로 결정 기록을 읽고 **산업분류 히트맵 8칸은
그대로 두고**, 조선·게임·2차전지는 `KRX ... TOP 10 지수`라는 공식 이름과 `테마지수` 배지를
붙여 **별도 섹션**으로 분리했다. 화장품은 "정확히 대응하는 공식 지수를 확인하지 못해
표시하지 않습니다" 안내로 남겼다. 테스트 28개·빌드·라이트/다크 화면 확인까지 통과.

## 4. 마무리 의식 (§18.4)

```text
$verify-market-dashboard
현재 주식 대시보드를 다른 사람에게 공유해도 되는지 최종 검증해줘.
파일과 외부 설정은 바꾸지 말고 결과만 보고해줘.
```

`/diff`로 커밋 전 변경을 훑고, `/review`에서 "커밋하지 않은 변경"을 골라 리뷰시킨 뒤
커밋을 맡긴다. **문서 변경까지 함께 커밋하라고 명시**한다.

```text
이제 커밋해줘. 이번 히트맵 개선뿐 아니라 재시작 전에 갱신한 README와 AGENTS.md 문서
변경까지 함께 커밋해줘. 커밋 메시지에는 무엇을 바꿨는지뿐 아니라 왜 그렇게 했는지도
적어줘. 커밋 뒤에는 빠진 파일이 없는지 상태를 확인해줘.
```

이 실행의 최종 커밋: `144e2c5 feat: 업종과 테마 히트맵을 분리한다` (8파일).
