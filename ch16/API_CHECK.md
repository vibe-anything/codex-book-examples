# 공공데이터포털 API 확인 결과

확인일: 2026-07-01 KST

키 값은 출력하지 않았다. 각 API는 공공데이터포털 금융위원회 OpenAPI로 확인했다.

## 사용 API

| API | 엔드포인트 | 확인 결과 | 앱에서 쓰는 필드 |
| --- | --- | --- | --- |
| 지수시세정보 | `GetMarketIndexInfoService/getStockMarketIndex` | 성공. 확인 시 최신 `basDt=20260625`, 해당일 `totalCount=163` | `basDt`, `idxCsf`, `idxNm`, `clpr`, `vs`, `fltRt`, `trPrc` |
| 주식시세정보 | `GetStockSecuritiesInfoService/getStockPriceInfo` | 성공. 확인 시 최신 `basDt=20260629`, 해당일 `totalCount=2876` | `basDt`, `srtnCd`, `itmsNm`, `mrktCtg`, `clpr`, `fltRt`, `trPrc` |
| 상장종목정보 | `GetKrxListedInfoService/getItemInfo` | 성공. 확인 시 최신 `basDt=20260629`, 해당일 `totalCount=2762` | `basDt`, `srtnCd`, `mrktCtg`, `itmsNm` |

## 화면 영역별 요구 데이터와 처리

| 화면 영역 | 화면 칸 | 필요한 데이터 | 공식 API로 채움 | 처리 방식 |
| --- | --- | --- | --- | --- |
| 지수 카드 | KOSPI/KOSDAQ 지수값, 등락폭, 등락률, 거래대금 | 지수명, 종가 포인트, 전일대비, 등락률, 거래대금 | 가능 | 지수시세정보에서 `idxCsf`/`idxNm`으로 `코스피`, `코스닥`을 찾는다. |
| 지수 카드 | 상승/하락/보합 종목 수, 종목 상승 비율 | 시장구분, 종목별 등락률 | 가능 | 주식시세정보의 `mrktCtg`, `fltRt`를 KOSPI/KOSDAQ별로 집계한다. |
| 시장 열기 | 3% 이상 상승 종목 비율, 상승/하락 종목 수, 전체 거래대금 | 종목별 등락률, 거래대금 | 가능 | 공공데이터포털에 별도 "시장 열기" 지표는 없으므로 `fltRt >= 3` 비율로 계산한 지표를 명시해 표시한다. |
| 업종 히트맵 | 업종명, 등락률, 거래대금 | 공식 지수명, 지수 등락률, 거래대금 | 가능(매핑된 공식 지수만) | 지수시세정보에 존재하는 `SECTOR_INDEX_MAP` 지수만 표시한다. 매핑 지수가 없으면 해당 칸은 렌더링하지 않는다. |
| 종목 순위 | 상승률 상위, 하락률 상위, 거래대금 상위 | 종목명, 시장구분, 종가, 등락률, 거래대금 | 가능 | 주식시세정보를 `fltRt`, `trPrc` 기준으로 정렬해 상위 5개를 만든다. |
| 종목 검증 | 화면에 직접 표시하지 않음 | 상장 단축코드 | 가능 | 상장종목정보의 `srtnCd`로 주식시세 종목 코드를 검증한다. |

## 화면에서 빼거나 분리한 항목

| 항목 | 공식 API 처리 가능 여부 | 결정 |
| --- | --- | --- |
| 공공데이터포털이 제공하는 별도 "시장 열기" 원천 지표 | 불가 | 임의 지표처럼 보이지 않도록 `3% 이상 상승 종목 비율` 계산값으로 확정했다. |
| 실시간 개장 여부, 장중 가격, 초 단위 갱신 | 불가 | 현재 화면에 넣지 않는다. 세 API는 일별 기준 데이터다. |
| 외국인/기관 수급, 투자 추천, 관심 종목 | 불가 또는 범위 밖 | 현재 화면에 넣지 않는다. |

## 실패와 갱신 지연 처리

- 지수시세정보와 주식시세정보는 최신 기준일이 다를 수 있다. 앱은 지수 기준일과 종목 기준일을 따로 찾고 헤더에 함께 표시한다.
- API 오류, 비정상 `resultCode`, 빈 응답, 필수 지수 누락, 종목 데이터 부족이 발생하면 `exampleMarketData`로 fallback한다.
- fallback 데이터는 `dataNotice`에 실패 이유를 붙여 실제 데이터처럼 보이지 않게 표시한다.
