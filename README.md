# codex-book-examples

이 저장소는 「Codex로 하는 바이브코딩」의 예제 저장소로, AI 코딩 에이전트에 입력한 요청문과 그 결과물을 장별로 보관한다.

## 구성 원칙

- 각 장별로 폴더를 구성한다. `chNN` 폴더는 **그 장을 마친 상태**다. 중간 장부터 실습하려면 앞 장 폴더에서 시작한다. 예를 들어 8장을 실습하려면 `ch07`을 내려받는다.
- Part 2(4~11장)는 아파트 실거래가 앱, Part 3(12~18장)은 주식 대시보드다. 서로 다른 프로젝트이므로 코드를 이어받지 않는다.
- 4장은 버리는 실험과 이후 장으로 이어지는 본선을 나누어 `real-estate-quick`과 `real-estate-app` 두 폴더를 둔다. 5장은 `real-estate-app`을 이어받는다.
- 6장은 앱 코드를 바꾸지 않으므로 `ch06`에는 요청문만 두고, 코드 상태는 `ch05`와 같다.
- 12장은 `/plan`으로 세운 예시 데이터 대시보드에서 출발하므로 그 시작 상태를 `ch12-start`에 따로 둔다. `ch12`는 12장을 마친 상태다.
- 각 폴더마다 그 장에서 입력한 요청문을 정리한 `PROMPTS.md`를 둔다. 원고의 요청문과 같은 순서로 맞춘다.
- 실제 API 키는 어떤 폴더에도 두지 않는다. `.env`는 커밋하지 않고 견본만 남긴다. Part 2는 `.env.example`, Part 3은 원고 표기에 맞춰 `.env.sample`을 쓴다.
