# 실제 데이터 연결 결과

> 예제 저장소에 올리면서 실제 시세에서 나온 값(업종 등락률, 3% 이상 오른 종목 수와 시장 열기 비율)은 지웠다. 이 시세는 공공누리 제4유형이고 제3자 제공과 재배포가 금지돼 있다. 나머지는 실행이 남긴 그대로다.

## 현재 매핑 기준 (2026-10-17 갱신)

공식 지수 API 1회(1,000행)로 최신 응답의 기준일 `20261015`와 아래 명칭·분류를 확인했다. 키·인증 URL·응답 원본은 기록하지 않았다.

| 표시 | 정확한 idxNm | idxCsf |
|---|---|---|
| 조선 | KRX 조선 TOP10 지수 | 테마지수 |
| 게임 | KRX 게임 TOP 10 지수 | 테마지수 |
| 2차전지 | KRX 2차전지 TOP 10 지수 | 테마지수 |

기존 KRX 업종 8개에 이 세 TOP 10 테마를 추가한다. ‘업종·테마 히트맵’의 테마 카드에 ‘TOP 10 · 테마지수’를 표시한다. 정확한 명칭·분류·같은 기준일의 유효한 등락률이 없으면 제외하며 유사 지수로 대체하지 않는다. 화장품 대응 지수는 미확인으로 실제 데이터에서 제외한다. 예시 데이터에도 세 테마의 구분을 표시한다.

아래는 변경 전 검증의 역사 기록이며, 테마 제외 기준과 검증 결과는 현재 구현·배포의 증거가 아니다.

## 과거 기록 (2026-10-15)

확인 기준일: 2026-10-15. 지수 API 1회(1,000행), 종목 API 1회(2,867행)로
목록과 변환 결과를 확인했다. 인증 키와 원본 응답 파일은 저장소에 넣지 않았다.

기존 12개 업종의 명칭과 순서는 `lib/marketData.js`의 `sectorIndices`에 그대로
유지한다. 실제 화면에는 같은 기준일의 유효한 값이 있는 KRX 업종 지수만 남긴다.
`idxCsf === "KRX시리즈"`와 정확한 `idxNm`을 함께 검사한다.
누락되거나 잘못된 업종 값은 숨긴다. 종목 시세 합산, 테마 지수, 규모 지수,
다른 시리즈 또는 유사 업종으로 대체하지 않는다.

| 기존 업종 | 실제 화면 | 사용 지수 / 제외 이유 | 확인 등락률(%) |
|---|---|---|---:|
| 반도체 | 유지 | KRX 반도체 | (지움) |
| 자동차 | 유지 | KRX 자동차 | (지움) |
| 은행 | 유지 | KRX 은행 | (지움) |
| 증권 | 유지 | KRX 증권 | (지움) |
| 건설 | 유지 | KRX 건설 | (지움) |
| 철강 | 유지 | KRX 철강 | (지움) |
| 운송 | 유지 | KRX 운송 | (지움) |
| 방송통신 | 유지 | KRX 방송통신 | (지움) |
| 조선 | 제외 | KRX 조선 TOP10 지수는 테마지수이며 대응하는 KRX 업종 지수 없음 | — |
| 게임 | 제외 | KRX 게임 TOP 10 지수는 테마지수이며 대응하는 KRX 업종 지수 없음 | — |
| 2차전지 | 제외 | KRX 2차전지 TOP 10 지수 등은 테마지수이며 대응하는 KRX 업종 지수 없음 | — |
| 화장품 | 제외 | 대응하는 KRX 업종 지수 없음. KRX 필수소비재는 범위가 달라 사용하지 않음 | — |

| 사용 API | 오퍼레이션 | 화면에서 쓰는 데이터 |
|---|---|---|
| [금융위원회 지수시세정보](https://www.data.go.kr/data/15094807/openapi.do) | `GetMarketIndexInfoService/getStockMarketIndex` | 코스피·코스닥 종가/전일 대비/등락률, 최근 일별 종가 그래프, KRX 업종 등락률 |
| [금융위원회 주식시세정보](https://www.data.go.kr/data/15094808/openapi.do) | `GetStockSecuritiesInfoService/getStockPriceInfo` | 상승률·하락률·거래대금 상위 각 5개, 3% 이상 상승 종목 비율 |

서버가 지수 응답의 최신 기준일을 구한 뒤 그 날짜로 종목 전체를 조회한다.
종목 응답이 페이지로 나뉘면 전체 수를 채울 때까지 조회하며, 불완전한 목록은
순위나 시장 열기에 사용하지 않는다. KOSPI·KOSDAQ·KONEX 시세 행(우선주 포함)이
집계 대상이다. 확인 결과 전체 2,867개 종목으로 시장 열기를 계산했다(값은 지움). 종가는 `clpr`(원), 등락률은 `fltRt`(%), 거래대금은 `trPrc`(원)이며,
기존 화면의 억원 단위 포맷에 맞춰 거래대금만 100,000,000으로 나눈다.

기존 화면의 섹션과 배치는 유지한다. 실제 데이터일 때 예시 배지를 숨기고
기준일·종가·출처·일별 그래프임을 표시한다. API는 실시간 데이터가 아니며
공식 안내상 기준일 다음 영업일 오후 1시 이후 갱신된다.
요청 실패 시에는 기존 12칸을 포함한 예시 화면 전체로 돌아가고 예시 배지를 표시한다.
예시 원본 `data/marketSnapshot.js`는 변경하지 않았다.

검증: `npm run lint`, `npm test`(9개), `npm run build` 통과.
빌드한 앱의 임시 서버에서 HTTP 200과 실제 기준일, 코스피·코스닥 값,
KRX 업종 8칸, 제외 대상 4칸 및 예시 배지의 부재를 확인했다.
이 렌더링 검증에서 각 API를 추가로 1회씩 호출했다(이번 작업 총 각 2회).
임시 서버는 검증 후 종료했다. 오류 시 예시 데이터 복귀는 네트워크를 쓰지 않는
테스트에서 통신 오류·빈 응답·기준일 불일치·잘못된 숫자에 대해 확인했다.
